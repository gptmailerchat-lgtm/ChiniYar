# چینی‌یار — MVP 0.4

این نسخه روی چهار جریان اصلی تمرکز دارد:

1. مترجم تصویری چینی: دوربین زنده یا انتخاب عکس از گالری، OCR چینی، نمایش کادرهای متن و انتخاب ناحیه/خط با لمس.
2. Pinyin واژه‌ای: متن انتخاب‌شده به قطعه‌های واژه‌ای شکسته می‌شود و برای هر قطعه Pinyin نمایش داده می‌شود. این segmentation برای MVP مبتنی بر Android ICU است و برای واژه‌های پیچیده در نسخه‌های بعد باید با واژه‌نامه اختصاصی چینی‌یار بهبود یابد.
3. ترجمه چینی→فارسی روی دستگاه: مدل ML Kit یک‌بار دانلود می‌شود و بعد ترجمه آفلاین انجام می‌شود.
4. حمل‌ونقل آفلاین: داده‌های داخلی و شماتیک برای خطوط/ایستگاه‌های کلیدی شانگهای، پکن، گوانگژو، شنژن و هانگژو.

## فناوری
- Kotlin + Jetpack Compose
- CameraX 1.6.1
- ML Kit Chinese bundled OCR 16.0.1
- ML Kit Translation 17.0.3
- minSdk 23

## نکته درباره داده مترو
داده‌های مترو در این MVP «راهنما/شماتیک» هستند، نه مسیریابی لحظه‌ای. برای نسخه تجاری باید بسته‌های داده نسخه‌بندی‌شده و منبع مجاز/دارای مجوز برای نقشه و خطوط تعریف شود.

## اجرا
پروژه را در Android Studio باز کنید و Gradle Sync/Build را اجرا کنید. برای ساخت wrapper کامل، Android Studio باید در اولین Sync توزیع Gradle را دریافت کند.
