# 🇨🇳 ChiniYar — چینی‌یار

**چینی‌یار (ChiniYar)** یک اپلیکیشن اندرویدی فارسی‌محور برای سفر، خرید، تجارت و یادگیری کاربردی زبان چینی است.

هدف پروژه این است که کاربر در یک برنامه ساده به ابزارهای مهم مورد نیاز در چین دسترسی داشته باشد: **OCR چینی، ترجمه چینی به فارسی، عبارات کاربردی با Pinyin و تلفظ، راهنمای شهرها و نقشه‌های آفلاین مترو**.

> وضعیت فعلی: **MVP / نسخه آزمایشی قابل Build و نصب روی Android**

## 🎯 هدف پروژه

چینی‌یار برای موقعیت‌های واقعی مانند سفر به چین، خرید از بازارها، مذاکره تجاری، حمل‌ونقل شهری و یادگیری سریع عبارت‌های کاربردی طراحی شده است.

- خواندن نوشته‌های چینی از روی عکس
- ترجمه سریع چینی به فارسی
- استفاده از جمله‌های آماده در سفر، خرید و تجارت
- شنیدن تلفظ چینی
- مشاهده Pinyin همراه معنی فارسی
- دسترسی آفلاین به نقشه‌های شماتیک مترو
- آشنایی اولیه با شهرهای مهم چین
- معرفی Yajing Chinese به‌عنوان منبع آموزش زبان چینی

## ✨ امکانات

### 📷 مترجم تصویری چینی

- انتخاب تصویر از گالری
- OCR چینی با Google ML Kit
- نمایش متن استخراج‌شده
- ترجمه چینی → فارسی
- دانلود مدل‌های سنگین در زمان نیاز به‌جای bundled کردن همه مدل‌ها داخل APK
- کپی متن
- پخش تلفظ چینی

### 🀄 عبارات کاربردی

بیش از **۳۰ عبارت آماده** با متن چینی، Pinyin، معنی فارسی، دسته‌بندی و تلفظ.

دسته‌ها: **مکالمه، خرید، مذاکره، پرداخت، سفر، حمل‌ونقل، تاکسی، خدمات، شرایط اضطراری و تجارت.**

### 🚇 نقشه متروی آفلاین

برای پنج شهر مهم چین داده شماتیک داخل برنامه وجود دارد:

1. Shanghai — 上海 — شانگهای
2. Beijing — 北京 — پکن
3. Guangzhou — 广州 — گوانگژو
4. Shenzhen — 深圳 — شنژن
5. Hangzhou — 杭州 — هانگژو

برای هر شهر، خطوط منتخب، مسیر شماتیک و **نام هر ایستگاه مستقیماً روی نقشه آفلاین** نمایش داده می‌شود. فهرست متنی همان ایستگاه‌ها نیز زیر نقشه قرار دارد.

> نقشه‌های داخلی برای راهنمای سریع و آموزشی هستند و جایگزین مسیریابی لحظه‌ای یا داده رسمی اپراتور مترو نیستند.

### 🇨🇳 راهنمای شهرها

اطلاعات کوتاه درباره Shanghai، Beijing، Shenzhen، Guangzhou، Yiwu و Hangzhou.

### 🎓 Yajing Chinese

در صفحه اصلی، بنر معرفی آموزش زبان چینی **Yajing Chinese** قرار دارد و با لمس آن وب‌سایت باز می‌شود:

https://yajingchinese.ir/

## 🎨 آیکون و ظاهر برنامه

لوگوی ارائه‌شده توسط کاربر از Yajing Chinese به‌عنوان **آیکون لانچر برنامه** استفاده می‌شود و در چند چگالی `mipmap` قرار گرفته است.

رابط کاربری نیز از پس‌زمینه‌های گرافیکی سبک و رنگ‌های گرم قرمز/نارنجی استفاده می‌کند.

## 📦 کاهش حجم APK

برای جلوگیری از حجیم شدن خروجی:

- مدل OCR چینی به‌صورت bundled داخل APK قرار نمی‌گیرد و با Google Play services در زمان نیاز دریافت می‌شود.
- dependencyهای غیرضروری حذف شده‌اند.
- Release APK با **R8 minification** و **resource shrinking** ساخته می‌شود.
- Release APK برای تست با debug signing امضا می‌شود تا مستقیماً روی گوشی قابل نصب باشد.


```text

```

## 🚀 GitHub Actions و Release

Workflow پروژه با نام **Build and Release ChiniYar APK** بعد از Build موفق:

1. APK Release را می‌سازد.
2. وجود فایل APK را بررسی می‌کند.
3. APK را به‌عنوان Artifact ذخیره می‌کند.
4. در Push روی `main` یک GitHub Release جدید ایجاد می‌کند.
5. APK را مستقیماً به Release متصل می‌کند.

صفحه دانلود نسخه‌های منتشرشده:

https://github.com/gptmailerchat-lgtm/ChiniYar/releases
