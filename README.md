# 🇨🇳 ChiniYar — چینی‌یار

**ChiniYar (چینی‌یار)** یک اپلیکیشن اندرویدی فارسی‌محور برای سفر، خرید، تجارت و یادگیری زبان چینی است.

هدف پروژه این است که کاربر بتواند در یک برنامه واحد به ابزارهای ضروری برای کار با زبان چینی دسترسی داشته باشد: تشخیص متن چینی از تصویر، ترجمه چینی به فارسی، عبارات آماده، Pinyin، تلفظ و راهنمای متروی شهرهای مهم چین.

> وضعیت فعلی: **MVP / نسخه آزمایشی قابل Build و نصب روی Android**

## 🎯 هدف پروژه

چینی‌یار برای موقعیت‌های واقعی مانند سفر به چین، خرید از بازارها، مذاکره تجاری، حمل‌ونقل شهری و یادگیری سریع عبارت‌های کاربردی طراحی شده است.

### نیازهایی که پروژه پوشش می‌دهد

- خواندن نوشته‌های چینی از روی عکس
- ترجمه سریع چینی به فارسی
- استفاده از جمله‌های آماده در سفر و خرید
- شنیدن تلفظ چینی
- مشاهده Pinyin همراه معنی فارسی
- دسترسی سریع به اطلاعات شماتیک متروی شهرهای مهم چین
- آشنایی اولیه با شهرهای مهم چین

## ✨ امکانات

### 📷 مترجم تصویری چینی

- انتخاب تصویر از گالری
- OCR چینی با Google ML Kit
- نمایش متن استخراج‌شده
- ترجمه چینی → فارسی
- دانلود مدل ترجمه و استفاده آفلاین پس از آماده‌سازی مدل
- کپی متن
- پخش تلفظ چینی

### 🀄 عبارات کاربردی

بیش از ۳۰ عبارت آماده با متن چینی، Pinyin، معنی فارسی، دسته‌بندی و دکمه تلفظ.

دسته‌های فعلی شامل:

**مکالمه، خرید، مذاکره، پرداخت، سفر، حمل‌ونقل، تاکسی، خدمات، شرایط اضطراری و تجارت.**

نمونه‌ها:

- 你好 — Nǐ hǎo — سلام
- 谢谢 — Xièxie — ممنون
- 请慢一点说 — Qǐng màn yìdiǎn shuō — لطفاً کمی آهسته‌تر صحبت کنید
- 多少钱？ — Duōshao qián? — چند قیمت است؟
- 可以便宜一点吗？ — Kěyǐ piányi yìdiǎn ma? — می‌شود کمی ارزان‌تر حساب کنید؟
- 地铁站在哪里？ — Dìtiě zhàn zài nǎlǐ? — ایستگاه مترو کجاست؟
- 我要去这里 — Wǒ yào qù zhèlǐ — می‌خواهم به اینجا بروم
- 如果买一千个，价格是多少？ — اگر هزار عدد بخرم قیمت چقدر می‌شود؟
- 最小订单量是多少？ — حداقل تعداد سفارش چقدر است؟
- 我们可以加微信吗？ — می‌توانیم در WeChat همدیگر را اضافه کنیم؟

## 🚇 راهنمای مترو

در MVP برای ۵ شهر مهم چین بخش متروی درون‌برنامه‌ای وجود دارد:

1. Shanghai — 上海 — شانگهای
2. Beijing — 北京 — پکن
3. Guangzhou — 广州 — گوانگژو
4. Shenzhen — 深圳 — شنژن
5. Hangzhou — 杭州 — هانگژو

برای هر شهر:

- نقشه شماتیک داخلی
- چند خط مهم
- تعدادی ایستگاه کلیدی
- مسیرهای شماتیک برای درک سریع شبکه
- لینک نقشه آنلاین در صورت وجود منبع مناسب

> نقشه‌های داخلی برای راهنمای سریع و آموزشی هستند و جایگزین مسیریابی لحظه‌ای یا نقشه رسمی اپراتور مترو نیستند.

## 🔨 Build APK

پروژه دارای GitHub Actions برای Build خودکار APK است.

Workflow:

```text
Build and Release ChiniYar APK
```

دستور ساخت:

```bash
gradle --no-daemon :app:assembleDebug
```

خروجی:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 📦 انتشار APK

Workflow پس از Build موفق، علاوه بر Artifact، APK را به‌صورت GitHub Release نیز منتشر می‌کند. نسخه‌ها با tag خودکار از نوع زیر منتشر می‌شوند:

```text
v0.4.<run-number>
```

بنابراین کاربر نهایی می‌تواند از صفحه Releases مخزن، آخرین APK را دانلود کند.

## 🔐 مجوزها

- OCR به کیفیت و وضوح تصویر وابسته است.

- نقشه‌های مترو داخلی شماتیک هستند و مسیریابی زنده ارائه نمی‌کنند.

- برای انتشار تجاری بهتر است داده‌های مترو با منابع رسمی و مجوز مناسب نسخه‌بندی شوند.
