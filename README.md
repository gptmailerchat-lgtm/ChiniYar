# 🇨🇳 ChiniYar — چینی‌یار

**ChiniYar (چینی‌یار)** یک اپلیکیشن اندرویدی فارسی‌محور برای مسافران، خریداران، بازرگانان و زبان‌آموزانی است که با زبان چینی در سفر یا کسب‌وکار سروکار دارند.

هدف پروژه این است که کاربر بتواند بدون جابه‌جایی بین چند اپلیکیشن، در یک محیط ساده به **OCR چینی، ترجمه چینی به فارسی، عبارات کاربردی، تلفظ و راهنمای متروی شهرهای مهم چین** دسترسی داشته باشد.

> وضعیت فعلی: **MVP / نسخه آزمایشی قابل Build و نصب روی Android**

---

## 🎯 هدف پروژه

چینی‌یار برای حل چند نیاز رایج طراحی شده است:

- خواندن نوشته‌های چینی از روی عکس
- فهم سریع معنی یک عبارت یا تابلو به فارسی
- داشتن جمله‌های آماده برای خرید، سفر، تاکسی، هتل و تجارت
- شنیدن تلفظ چینی جملات
- دسترسی سریع به اطلاعات شماتیک متروی شهرهای مهم چین
- تمرین و یادگیری زبان چینی در کنار استفاده عملی در سفر و تجارت

---

## ✨ امکانات اصلی

### 📷 مترجم تصویری چینی

کاربر می‌تواند یک تصویر را از گالری انتخاب کند. برنامه متن چینی را با **ML Kit Chinese OCR** استخراج می‌کند و سپس امکان ترجمه آن به فارسی را فراهم می‌کند.

ویژگی‌های این بخش:

- انتخاب عکس از گالری
- تشخیص متن چینی از تصویر
- نمایش متن استخراج‌شده
- ترجمه چینی → فارسی
- استفاده از مدل ترجمه ML Kit
- امکان کپی متن
- امکان پخش تلفظ چینی

### 🀄 عبارات کاربردی

مجموعه‌ای از عبارات آماده برای موقعیت‌های واقعی در چین، همراه با:

- متن چینی
- Pinyin
- معنی فارسی
- دسته‌بندی کاربرد
- دکمه پخش تلفظ

دسته‌های فعلی شامل:

**مکالمه، خرید، مذاکره، پرداخت، سفر، حمل‌ونقل، تاکسی، خدمات، شرایط اضطراری و تجارت.**

نمونه‌ها:

- 你好 — Nǐ hǎo — سلام
- 多少钱？ — Duōshao qián? — چند قیمت است؟
- 可以便宜一点吗？ — Kěyǐ piányi yìdiǎn ma? — می‌شود کمی ارزان‌تر حساب کنید؟
- 地铁站在哪里？ — Dìtiě zhàn zài nǎlǐ? — ایستگاه مترو کجاست؟
- 我要去这里 — Wǒ yào qù zhèlǐ — می‌خواهم به اینجا بروم
- 如果买一千个，价格是多少？ — Rúguǒ mǎi yìqiān gè, jiàgé shì duōshao? — اگر هزار عدد بخرم قیمت چقدر می‌شود؟
- 最小订单量是多少？ — Zuìxiǎo dìngdān liàng shì duōshao? — حداقل تعداد سفارش چقدر است؟
- 我们可以加微信吗？ — Wǒmen kěyǐ jiā Wēixìn ma? — می‌توانیم در WeChat همدیگر را اضافه کنیم؟

تعداد عبارات در MVP به بیش از ۳۰ مورد رسیده است.

### 🚇 راهنمای متروی چین

نسخه MVP دارای بخش مترو برای **۵ شهر مهم چین** است:

1. Shanghai — 上海 — شانگهای
2. Beijing — 北京 — پکن
3. Guangzhou — 广州 — گوانگژو
4. Shenzhen — 深圳 — شنژن
5. Hangzhou — 杭州 — هانگژو

برای هر شهر:

- نقشه شماتیک داخل اپ
- نمایش چند خط مهم
- نمایش مجموعه‌ای از ایستگاه‌های کلیدی
- مسیرهای شماتیک برای درک سریع ارتباط ایستگاه‌ها
- لینک نقشه آنلاین/به‌روز در صورت وجود منبع مناسب

> **توجه:** نقشه‌های داخل اپ در این نسخه برای راهنمای سریع و آموزشی هستند و جایگزین مسیریابی لحظه‌ای، اطلاعات رسمی اپراتور مترو یا نقشه زنده نیستند.

### 🇨🇳 راهنمای شهرهای چین

- Shenzhen / شنژن

## 🏗 ساخت APK

Build پروژه با GitHub Actions انجام می‌شود.

Workflow اصلی:

```text
.github/workflows/build-apk.yml
```

مراحل Build:

```bash
gradle --no-daemon clean
gradle --no-daemon --stacktrace :app:assembleDebug
```

فایل خروجی:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Artifact خروجی GitHub Actions:

```text
chiniyar-debug-apk
```

## 📱 نصب APK برای تست

بعد از Build موفق در GitHub Actions:

1. وارد تب **Actions** شوید.
2. Workflow با نام **Build ChiniYar APK** را باز کنید.
3. آخرین Run موفق را انتخاب کنید.
4. از قسمت **Artifacts** فایل `chiniyar-debug-apk` را دریافت کنید.
5. ZIP را استخراج کرده و `app-debug.apk` را روی گوشی Android نصب کنید.

برای نصب ممکن است لازم باشد اجازه نصب برنامه از منبع مورد اعتماد/مرورگر را در تنظیمات Android فعال کنید.

نسخه فعلی برای قابلیت‌های اصلی به مجوزهای معمول Android نیاز دارد. تشخیص متن از تصویر و ترجمه توسط کتابخانه‌های ML Kit انجام می‌شود.

## ⚠️ محدودیت‌های فعلی MVP

این پروژه هنوز یک نسخه MVP است. مهم‌ترین محدودیت‌ها:

- نقشه‌های مترو داخل برنامه شماتیک هستند.
- مسیریابی لحظه‌ای، وضعیت تأخیر قطارها و اطلاعات Live در برنامه وجود ندارد.
- دقت OCR به کیفیت، زاویه و خوانایی تصویر وابسته است.
- ترجمه ماشینی ممکن است برای اصطلاحات تجاری یا تخصصی نیاز به اصلاح انسانی داشته باشد.
- Pinyin و فرهنگ واژگان اختصاصی هنوز در سطح نسخه حرفه‌ای/تجاری نیست.
- محتوای شهرها در این نسخه خلاصه و راهنماگونه است.
